## 文件说明

### 1. RustDesk.app
主应用程序，拖到 Applications 文件夹即可安装。

### 2. Setup_Permissions.command
权限配置助手脚本，双击即可运行。

**功能**：
- 自动移除应用的隔离属性（需要管理员密码）
- 逐步引导用户配置必要的系统权限：
  - 辅助功能（Accessibility）
  - 屏幕录制（Screen Recording）
  - 输入监控（Input Monitoring，macOS 11.0+）
- 可选择在配置完成后自动启动 RustDesk

**使用方法**：
1. 先将 RustDesk.app 拖到 Applications 文件夹
2. 双击 `Setup_Permissions.command`
3. 按照提示操作

### 3. README.txt
简要安装说明，包含中英文双语。

## 用户体验流程

1. **打开 DMG** → 看到 3 个文件和 Applications 快捷方式
2. **拖动 RustDesk.app** → 到 Applications 文件夹
3. **双击 Setup_Permissions.command** → 运行权限配置助手
4. **输入管理员密码** → 移除隔离属性
5. **按照提示** → 在系统设置中授予权限
6. **启动 RustDesk** → 开始使用
